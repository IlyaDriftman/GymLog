# GymLog — Telegram Mini App

Та же программа Push / Pull / Legs, но план можно собирать самому: день — стопка упражнений, внутри каждого свои подходы и повторения. На тренировке пишешь вес и повторы, в истории остаются прошлые веса. У упражнения есть техника, группы мышц и замена, если штанга, гантели или тренажёр заняты.

База пока только из упражнений текущей программы. Её можно расширить следующим шагом.

Открывается и в обычном браузере, и внутри Telegram. iPhone- и Android-приложения в `GymLog/` и `GymLogAndroid/` по-прежнему с фиксированным планом и своей базой на телефоне.

## Как посмотреть у себя

Из папки `telegram`:

```bash
python3 -m http.server 8765
```

Открой `http://127.0.0.1:8765`.

Данные на телефоне сохраняются сразу. Если открыть GymLog внутри Telegram, план и история дополнительно записываются в аккаунт Telegram и подтягиваются на другом телефоне с тем же аккаунтом. Кнопка «Данные» по-прежнему выгружает JSON.

## Как поставить в Telegram

Страница должна открываться по HTTPS. Залей папку `telegram` на любой статический хостинг (GitHub Pages, Cloudflare Pages, свой сервер) так, чтобы `index.html` был адресом мини-приложения.

1. В [@BotFather](https://t.me/BotFather) открой бота.
2. Bot Settings → Configure Mini App (или Menu Button) и вставь HTTPS-адрес `index.html`.
3. Открой бота и запусти приложение.

Кнопка «Назад» в Telegram возвращает на предыдущий экран. Исходный план возвращается кнопкой «Вернуть исходную программу» — история при этом не стирается.
